# Mediascope - data analyst intern, spring 2026
Тестовое задание на позицию стажера аналитика данных

Задание с финального этапа собеседования на позцию стажера аналитика данных

Финальный этап проходил в формате лайв-кодинга, задача:
+ загрузить файл
+ рассмотреть каждый признак, при необходимости обработать:
  + заменить некорректные значения (я заменяла медианой)
  + заполнить пропуски
  + скорректировать тип данных
+ выполнять дополнительные задания:
  + добавлять новые признаки на основе старых (apply)
  + строить сводные таблицы
  + объединять таблицы (merge)
